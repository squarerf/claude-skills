## 更新流程

### 第一阶段：更新前准备

```bash
# 1. 检查当前版本
claude --version

# 2. 备份配置文件（重要！）
cp -r ~/.claude/ ~/.claude-backup-$(date +%Y%m%d-%H%M%S)/

# 3. 查看更新内容
claude update

# 4. 关闭所有 Claude 会话（避免文件占用）
# 关闭终端中的 Claude 进程，或直接重启终端
```

### 第二阶段：执行更新

```bash
# 5. 根据安装方式选择更新命令

# npm 方式（推荐）
npm install -g @anthropic-ai/claude-code@latest

# 或 winget 方式
winget upgrade Anthropic.ClaudeCode

# 或 brew 方式（macOS）
brew upgrade claude-code
```

### 第三阶段：更新后验证

```bash
# 6. 验证版本已更新
claude --version

# 7. 检查配置是否保留
ls ~/.claude/settings.json
ls ~/.claude/skills/
ls ~/.claude/.mcp.json

# 8. 检查插件兼容性
claude
/plugin list

# 9. 测试核心功能
# - 读写文件
# - 执行命令
# - 调用技能
```

### 第四阶段：收尾工作

```bash
# 10. 重启终端或 IDE（确保新版本完全生效）

# 11. 确认一切正常后，可删除旧备份（可选）
# rm -rf ~/.claude-backup-旧日期/
```

## 一键备份脚本

```bash
#!/bin/bash
# 保存为 backup-claude.sh
BACKUP_DIR=~/.claude-backup-$(date +%Y%m%d-%H%M%S)
cp -r ~/.claude/ $BACKUP_DIR
echo "已备份到: $BACKUP_DIR"
```

## 常见问题速查

| 问题 | 解决方案 |
|------|----------|
| winget 更新失败（证书错误） | 改用 npm 方式更新 |
| 多版本冲突 | `where claude` 查看路径，删除旧版本 |
| 文件被占用 | 重命名旧文件：`mv old.exe old.exe.bak`，重启后删除 |
| 命令找不到 | 检查 PATH：`npm config get prefix` |
| 配置丢失 | 从备份恢复：`cp ~/.claude-backup-日期/* ~/.claude/` |
| 插件异常 | 重新安装：`/plugin install 插件名` |

## 核心原则

1. **只用一种安装方式**（推荐 npm，避免冲突）
2. **更新前必备份**（配置文件无价）
3. **关闭会话再更新**（避免文件占用）
4. **更新后必验证**（版本 + 配置 + 功能）

## 关于会话关闭

- 关闭当前 Claude 会话会结束本次对话
- 更新前建议先完成当前对话或记录重要内容
- 可以在其他终端窗口执行更新命令
- 或更新后重启 Claude，新会话自动使用新版本

## 检查安装方式

```bash
# 查看 Claude 安装路径
where claude

# 查看当前版本和更新信息
claude update
```

## 多版本处理

如果存在多个安装版本，建议只保留一个：

```bash
# 删除 winget 版本
winget uninstall Anthropic.ClaudeCode

# 删除旧 npm 版本
npm uninstall -g @anthropic-ai/claude-code@旧版本号
```
